# MediatorInstanceManager  

The MediatorInstanceManager is a harmonized management interface for creating, listing and deleting the MediatorProcesses inside a MediatorVM.  
The original definitions can be found [here](https://github.com/openBackhaul/MediatorInstanceManager).  

### Interface  

Description of the [MediatorInstanceManager API](./mim.yaml) in regards with the offered MeasurementFunctions and ImplementationFunctions.
